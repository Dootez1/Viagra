# Lotus Dels | P2P Гарант-бот (aiogram 3, SQLite, Telegram Stars)

Полноценный P2P гарант-бот для автоматических сделок с NFT и подарками Telegram, созданный по структуре **Lotus Dels | Гарант бот**.

## 🚀 Основные возможности

1. **Главное меню**:
   - `🛒 Создать сделку` — пошаговое создание сделки (FSM).
   - `💰 Баланс` — балансы (RUB, Crypto, Stars), статистика сделок и вывод средств с проверкой условий.
   - `📋 Мои сделки` — список активных и архивных сделок с возможностью завершения сделки покупателем.
   - `🪪 Мои реквизиты` — проверка и привязка реквизитов.
   - `👥 Рефералы` — реферальная программа 50% с персональной deep-link ссылкой.
   - `💬 Отзывы` — связь с менеджером.
   - `🌐 Язык / Lang` — выбор языка интерфейса.
   - `🆘 Техподдержка ↗` — прямая ссылка на саппорта `@HypedDealsSupport`.

2. **Сценарий создания сделки**:
   - **Шаг 1**: Выбор роли («👑 Я продавец» / «🛍 Я покупатель»).
   - **Шаг 2**: Выбор валюты (Рубли, Гривны, Буны, Тенге, GRAM, USDT, Stars).
   - **Шаг 3**: Ввод суммы сделки с автоматическим расчетом комиссии 3% сервису.
   - **Шаг 4**: Ввод ссылки на NFT или подарок (`t.me/nft/...`).
   - **Шаг 5**: Генерация уникального ID сделки (хеша), сохранение в SQLite, отправка карточки со ссылкой и кнопкой для шеринга.

3. **Завершение сделки**:
   - Покупатель нажимает «✅ Успешно завершить сделку».
   - Продавцу и покупателю моментально выводится сообщение:
     ```text
     🎉 Сделка #<ID> успешно завершена!

     Спасибо за доверие ❤️
     ```

4. **Инлайн-приглашения (Inline Query)**:
   - Кнопка `📨 Поделиться сделкой в чате` с переходом в любой чат.
   - Генерация интерактивной карточки сделки с кнопкой `🤝 Принять сделку`.

---

## ⚠️ ВАЖНО: Включение Inline-режима в @BotFather

Если при нажатии **«📨 Поделиться сделкой в чате»** в Telegram ничего не появляется (нет карточки и кнопок), это означает, что в настройках бота в Telegram отключен инлайн-режим (`supports_inline_queries = False`).

### Как включить:
1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте команду:
   ```text
   /setinline
   ```
3. Выберите вашего бота (например, `@TonnelOfferBot`).
4. Введите плейсхолдер для строки ввода, например:
   ```text
   Введите #ID_сделки...
   ```
5. После этого Telegram мгновенно активирует выпадающее окно с карточками сделок!

## 🛠 Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Убедитесь, что в файле `.env` указаны необходимые переменные:
   ```env
   BOT_TOKEN=YOUR_BOT_TOKEN_HERE
   SUPPORT_USERNAME=HypedDealsSupport
   REVIEWS_CHANNEL=HypedDealsReviews
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```
